Software engineer and technical lead who builds web applications, developer tools, and the music software that I wish existed.

I work with technologies such as TypeScript/JavaScript, Vue, React, React Native, PHP, Python, SQL, and AWS, and have experience ranging from modern greenfield applications to large production legacy systems.

**More about me → [jonlervold.com](https://jonlervold.com)**

## Selected Projects

**[jontools](https://github.com/jonlervold/jontools)** - A suite of music-minded web tools (e.g. MIDI invert/transform, mid/side audio isolation), built for the gaps where existing software doesn’t quite fit.

**[TabArea](https://github.com/jonlervold/tabarea)** - A community preservation effort of TabIt.net's huge guitar tablature library (~44k tabs), with an added advanced search tool not present on the original site.

**[Color Horizons](https://github.com/jonlervold/color-horizons)** - A browser-based microtonal scale generator and synthesizer that lets you compare custom tunings against 12-TET and the harmonic series, play them live, and export .scl files to use with other instruments.

**[Musicbox](https://github.com/jonlervold/musicbox)** - My personal Spotify alternative, the best of both worlds between streaming and actually owning music via an MP3 collection.
